# Publishing a WorldForge Resource Pack

This is the owner/admin workflow for adding a permanent downloadable version.

1. Open the WorldForge Resource Merger website.
2. Merge the older complete pack and newer complete pack.
3. Save the finished ZIP.
4. Click **Copy release notes**.
5. Open this GitHub repository.
6. Click **Releases**.
7. Click **Draft a new release**.
8. Create a new tag, for example `v12`.
9. Set the release title, for example `WorldForge Resource Pack v12`.
10. Drag the merged ZIP into the release assets box.
11. Paste the release notes copied by the merger.
12. Click **Publish release**.

The website will automatically show the release in the Downloads page. Previous releases remain downloadable.
