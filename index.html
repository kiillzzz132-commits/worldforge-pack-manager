 HOW IT WORKS

        
Built for giant packs.

        
The merger is intentionally serverless: your resource packs never need to be uploaded to a web server before they can be combined.

      


      

        
01
Local processing
The browser reads both ZIPs on your computer. There is no cloud upload step and therefore no web-host upload-size bottleneck.

        
02
Compressed copying
Unchanged archive entries are copied in pass-through mode when possible. Only merge-sensitive files need to be opened and processed.

        
03
Minecraft-aware JSON
Font providers, sound registries, translations, atlases and tags preserve entries from both packs instead of losing one side.

        
04
Permanent releases
Official versions are stored as GitHub Release assets, separate from the website itself, so old downloads remain available.

        
05
Exact SHA-1
The finished file is hashed locally and produces the exact SHA-1 Minecraft expects for resource-pack-sha1.

        
06
Privacy by design
The merger needs no accounts, cookies, database or uploaded copies of visitors' resource packs.

      


      

        
Large Pack Mode

        
For especially large packs, Chromium browsers can write the merged ZIP directly to disk instead of holding the entire finished archive in browser memory. Standard mode remains available everywhere else.
